# Security Policy

## Supported Versions

The latest published version of `folio-generator-js` and `folio-generator-ts` on npm is supported with security fixes.

| Package             | Supported |
| -------------------- | --------- |
| folio-generator-js  | Latest    |
| folio-generator-ts  | Latest    |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately using [GitHub's private vulnerability reporting](https://github.com/AnderCMD/Generador-de-folios/security/advisories/new) for this repository.

Please include:

-   A description of the vulnerability and its potential impact.
-   Steps to reproduce the issue.
-   The affected package(s) and version(s).

We will do our best to acknowledge reports within a few days and to release a fix as soon as possible.
